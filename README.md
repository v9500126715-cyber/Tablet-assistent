# Помощник планшета — прототип 0.1
Android 8+, целевое устройство Xiaomi Pad 6 / Android 14.
Это диктовка, не ИИ-агент и не подключение к текущему чату ChatGPT.

## Сборка
GitHub Actions → Build APK → последний запуск → Artifacts → tablet-assistant-apk.
Скачайте ZIP, распакуйте, установите app-debug.apk. Это тестовый APK с debug-подписью.

## Использование
Откройте приложение → специальные возможности → включите «Помощник планшета».
Выберите обычное текстовое поле в другом приложении, нажмите «Диктовать», проверьте текст, нажмите «Вставить».
**Содержимое поля заменяется целиком.** Парольные поля исключены.
Долгое нажатие на кнопку выключает сервис.
Голосовое распознавание зависит от установленного провайдера (например Google) и может отправлять ему аудио.
Не сохраняем экран или диктовку; API-ключей нет.
На Android 13+ установка APK может потребовать разрешения ограниченных настроек через сведения о приложении.
Не все приложения поддерживают Accessibility ACTION_SET_TEXT.

## Проверка на устройстве
1. Проверить вставку русского текста в пустое поле заметок.
2. Проверить замену существующего текста после подтверждения.
3. Проверить отмену: поле не меняется.
4. Проверить сообщение об отсутствии выбранного поля.
5. Проверить отключение долгим нажатием.
Компиляция и тестирование на устройстве — отдельные этапы; статус сборки виден в Actions.
